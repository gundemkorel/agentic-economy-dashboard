# Agentic Economy Research Thesis

## Core objective

Identify businesses whose economics improve mechanically as autonomous machine activity increases, where the improvement is not yet adequately reflected in consensus estimates, valuation, or investor expectations.

This is not a collection of AI-related stocks, a prediction of the winning frontier model, or a management-keyword screen.

## Core mechanism

The central variable is machine actions per unit of human intent.

One human intention can create many machine events: retrieval, API calls, context lookup, authentication, policy checks, communication, retries, verification, and eventually transactions. Wave 2 is therefore about activity, not merely generated intelligence.

The project also tracks AI-mediated existing activity: routine enterprise events increasingly routed through models for classification, extraction, retrieval, routing, policy, and action. This may create a second multiplier without requiring full autonomy.

## Three waves

1. Wave 1 — Intelligence: models generate content and reasoning; recognized beneficiaries include chips, compute, data centers, and model providers.
2. Wave 2 — Activity: models interact with systems and take actions; potential bottlenecks include traffic, APIs, data, inference, context, telemetry, security, identity, observability, communication, and control planes.
3. Wave 3 — Economy: delegated authority, money, procurement, logistics, and physical execution. This is primarily a discovery watchlist for now.

The project focuses roughly 70–80% on Wave 2 and 20–30% on Wave 3 observation. These are conceptual research weights, not portfolio allocation targets.

## Investment heuristic

We are not trying to predict who wins AI. We are trying to identify scarce, billable resources whose consumption rises as machines take more actions—and identify those economics before consensus recognizes the change.

Ask:

1. If agent activity rises 100×, whose bill automatically gets larger?
2. What does the incremental revenue cost to serve?
3. How much is already reflected in today's price?

## Falsifiability

The thesis weakens if agents remain primarily assistive, AI-related consumption is bundled into flat-rate products, workloads consolidate into hyperscaler-native services, AI pricing falls faster than volume grows, or candidate companies fail to retain the mix shift.
