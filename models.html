Model discipline

What this lab does not claim

Read before using
A

Not consensus

The scenarios are the project’s own assumptions. They are not analyst estimates, management guidance beyond the stated baseline, or a target price.

B

Not a complete DCF

The output is a transparent FCF-multiple bridge. It is deliberately incomplete so the unknown capital and dilution path remains visible.

C

Upgrade through evidence

A scenario changes only after CIS conversion, agent-control monetization, margins, and cash returns show up in dated reporting.
